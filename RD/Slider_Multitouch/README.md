## 🎯 Objectif du Projet

Développer un slider capacitif multitouch 1D de **217mm × 8mm** avec détection de **8 doigts simultanés** utilisant le contrôleur Infineon CYAT61658-56LWA41.

## ✅ Statut: FAISABLE

La solution technique a été validée avec les contraintes suivantes:
- Overlay plastique: 2mm d'épaisseur
- PCB double couche
- Environnement: châssis aluminium + carte mère à 1mm
- Pattern capteur: Manhattan-3 (MH3)

## 📊 Résumé Technique

| Paramètre | Valeur |
|-----------|--------|
| **Contrôleur** | CYAT61658-56LWA41 (56-pin QFN) |
| **Configuration** | 41 RX × 2 TX = 82 intersections |
| **Accuracy** | 0.5mm typique |
| **Refresh Rate** | 60-250 Hz |
| **Doigts simultanés** | 8 (10 max) |
| **Budget prototype** | ~1000€ |
| **Délai développement** | 10 semaines |
